# Propósito Educacional IA

Crie uma plataforma educacional para o Hackathon Hacktudo 2026 focada em 'Tecnologia com Propósito e Educação'. Deve conter duas áreas principais: 1) Painel do Professor com upload de PDFs, seleção de quais PDFs ficam ativos para a IA, Trava Metacognitiva para configurar o limite de prompts por aluno (ex: 5 prompts) e dashboard de dúvidas da turma com métricas de engajamento; 2) Área do Aluno (mobile-first) com chat de tutor pedagógico, contador visível em tempo real (ex: '3/5 prompts restantes'), bloqueio automático do campo de texto e envio ao esgotar a cota, e respostas baseadas nos materiais ativos. Design moderno e intuitivo com Tailwind CSS.
